⚠️ Falta configurar Firebase

Este archivo necesita las credenciales de tu proyecto Firebase para funcionar.

Abre el archivo HTML, busca la sección firebaseConfig cerca del inicio del <script>, y reemplaza los valores "PEGA_AQUI" por los datos reales de tu proyecto (los obtienes en Firebase Console → Configuración del proyecto → Tus apps).

⚠️ No se pudo cargar Firebase

Este archivo necesita internet para conectarse a la base de datos, y no logró cargar la librería de Firebase (gstatic.com). No es un problema de credenciales — no hace falta tocar el firebaseConfig.

Revisa tu conexión a internet y vuelve a abrir el archivo. Si tienes conexión pero el error persiste, tu red o firewall podría estar bloqueando www.gstatic.com.

⚠️ No se pudo conectar a Firebase

Las credenciales están cargadas, pero ocurrió un error inesperado al conectar con tu proyecto de Firebase.

Revisa la consola del navegador (F12) para ver el detalle del error, o avisa al equipo con una captura de esta pantalla.
